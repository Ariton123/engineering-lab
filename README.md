# Engineering Lab

This repository is a space for technical experiments, prototypes, notes, and engineering explorations.

Not every project in this repository is meant to be a polished final product. Some parts are small tests, some are research notes, and others are practical experiments used to understand how systems behave in real-world scenarios.

---

## Purpose 

The goal of this repository is to document my technical learning process and preserve useful engineering work over time.

It includes experiments related to software development, system interaction, automation, networking, IoT, game development tools, and other technical areas I explore.

---

## Topics

Current and future topics may include:

- Software engineering experiments
- Unity and C# tools
- Python scripts
- IoT and networking experiments
- BACnet and building automation exploration
- Technical notes from hackathons
- Small utilities and prototypes
- System design observations
