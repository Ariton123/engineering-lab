# Domotics Hackathon 2026 (Thun, Switzerland)

This repository contains documentation, notes, screenshots, experiments, and technical findings collected during the Domotics Hackathon 2026 held in Thun, Switzerland.

## Event Context

The hackathon focused on building automation and smart infrastructure systems, including BACnet-based devices, DALI lighting systems, and industrial control technologies commonly used in modern building management environments.

## Activities

During the event, multiple devices and controllers were analyzed using engineering and building-automation tools, including:

* BACnet device discovery and enumeration
* Object and property analysis
* Service capability inspection
* BACnet write operations and testing
* DALI lighting interaction experiments
* Network exploration and protocol investigation

## Technologies

* BACnet
* DALI
* Yabe
* BACteria
* Python
* Building Automation Systems

## Outcome

The hackathon experiments and collected technical material were developed into the following research paper:

**Security and Human-Centered Assessment of BACnet-Controlled DALI Infrastructure in an Educational Building Automation Testbed**

- Published as a preprint on arXiv
- arXiv identifier: `2606.17089`
- Paper: https://arxiv.org/abs/2606.17089

The paper extends the original hackathon work into a structured security and human-centered assessment of BACnet-controlled DALI infrastructure.
