# Introduction to Recommender Systems — Exercises

## Overview

This repository contains coursework exercises completed for the **Introduction to Recommender Systems** course during the master's program in Computer Science.

The exercises were mainly developed in Python using Jupyter/Google Colab notebooks. They explore core concepts in recommender systems, including content-based recommendation, user profiles, item profiles, prediction scoring, model comparison, and bias introduced by different computational choices.
