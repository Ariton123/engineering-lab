# Simplified Travel - User-Centered Design Coursework

## Overview

Simplified Travel is a User-Centered Design coursework project developed at the University of Fribourg. The project explored the design of a student-focused travel planning platform that helps users organize trips with friends while balancing simplicity, flexibility, comfort, and budget awareness.

The project followed a user-centered design process, including user interviews, persona development, UX principle selection, paper prototyping, Wizard-of-Oz testing, feedback analysis, and final design iteration.

## Project Context

The design challenge focused on creating a travel planning experience that supports different user needs, including budget-conscious travelers, comfort-seeking users, spontaneous travelers, and users who prefer planning trips collaboratively with friends.

The final UX vision was to create a familiar and simple travel booking experience for students and groups, with a focus on:

- recognition rather than recall
- aesthetic and minimalist design
- user control and freedom
- simple group travel coordination
- clearer pricing and invitation flows

## Design Process

1. **User Research**  
   Initial interviews were conducted to understand travel habits, planning preferences, comfort expectations, frustrations, and expectations from travel platforms.

2. **Persona Development**  
   Two personas were created to represent different types of users, including budget-conscious independent travelers and comfort-seeking explorers.

3. **UX Principles and Heuristics**  
   The design direction was guided by UX principles such as Nielsen's heuristics, especially user control and freedom, recognition rather than recall, and aesthetic/minimalist design.

4. **Paper Prototype**  
   A low-fidelity paper prototype was created to explore core interactions such as searching travel options, viewing packages, inviting friends, reviewing group trip choices, and handling payment-related decisions.

5. **Wizard-of-Oz Testing**  
   The paper prototype was tested using a Wizard-of-Oz approach, allowing user interactions to be simulated before implementing a digital system.

6. **User Testing and Iteration**  
   Feedback from test participants was summarized and used to improve the design. Key improvements included clearer friend management, better package descriptions, improved invitation flows, clearer price-per-person information, and better visual consistency.
