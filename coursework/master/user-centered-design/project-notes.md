# Project Notes - Simplified Travel UCD

## Why this project is portfolio-worthy

This coursework project is valuable because it documents a complete UCD pipeline rather than only a final presentation. It includes early user research, personas, design principles, low-fidelity prototyping, Wizard-of-Oz testing, user feedback summaries, and final design iteration.

## Mid-term materials

The mid-term phase includes:

- initial design challenge and objective
- UX best practices and selected heuristics
- user interviews
- two personas
- early concept direction

## Final materials

The final phase includes:

- paper prototype and Wizard-of-Oz testing
- first user testing summary
- second user testing summary
- final presentation with changed UX vision and design iterations

## Main design takeaways

- Users need simple and clear travel planning flows.
- Visual clarity matters strongly in travel browsing.
- Group planning requires clear friend management, invitations, and trip decision states.
- Price per person and total price must be visible.
- Payment and split-bill flows need strong feedback and error prevention.
- Consistent visual design is important for perceived professionalism.

## GitHub description

User-Centered Design coursework project for a collaborative student travel planning concept, including interviews, personas, paper prototyping, Wizard-of-Oz testing, user feedback analysis, and final UX iteration.
