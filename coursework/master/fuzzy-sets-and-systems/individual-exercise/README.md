# Fuzzy Logic Individual Exercise

This folder contains individual exercise notebooks completed during the Fuzzy Sets and Systems I course.

The notebooks cover fuzzy control systems, fuzzy clustering, and a custom fuzzy gift selector exercise that later supported the development of the Giftanator project.

## Contents

- `01_FuzzyControlSystem.ipynb` — fuzzy control system exercise
- `02_FuzzyClustering.ipynb` — fuzzy clustering exercise
- `03_FuzzyGiftSelector.ipynb` — individual fuzzy gift selector deliverable
- `Introduction.md` — introductory course exercise notes
- `requirements.txt` — Python dependencies
- `Dockerfile` — optional notebook environment setup

## Note

The first two notebooks were completed as guided course exercises. The third notebook applies the learned fuzzy logic concepts to a custom gift recommendation problem.
