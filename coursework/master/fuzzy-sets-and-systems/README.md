# Giftanator

Giftanator is a Python-based fuzzy logic application developed as part of the Fuzzy Sets and Systems I course during my Master's studies in Computer Science.

The project explores how fuzzy reasoning can support gift recommendation decisions based on contextual information about the recipient, the relationship, and the occasion.

## Project Overview

The application asks the user a set of questions through a character-based interaction flow. Based on the provided answers, the system applies fuzzy logic rules to recommend suitable gift options.

The concept was developed as a playful reference to the original Akinator-style experience, where a character asks questions in order to guess what the user is thinking about. Instead of guessing a fictional character, Giftanator uses a similar interaction idea to recommend a suitable gift.

The goal of the project was to model uncertainty and subjective decision-making in a practical scenario where inputs are not always binary or exact.
