# Metamodeling Course Project

This project was developed during my Master's studies in Computer Science as part of a metamodeling course project.

The work focuses on domain-specific modeling, notation design, and implementation using ADOxx-related technologies, including AdoScript, `.adl`, `.abl`, and model instance files.

## Project Overview

The project explores how custom modeling concepts, graphical notations, and model instances can be defined and implemented within a metamodeling environment.

The submitted work includes the final project files, model instances, custom notation icons, and presentation materials.

## Technologies and Formats

- ADOxx
- AdoScript
- `.adl` model/library files
- `.abl` script files
- `.asc` files
- Graphical notation icons
- Model instance documentation

## Repository Structure

- `final-submission/` — final submitted project files
- `model-instances/` — exported model instance examples and diagrams
- `icons-for-notations/` — custom graphical notation assets
- `presentations/` — course project presentation materials
