# Crime Hotspot Identifier

This project was developed as part of the Seminar Urban Computing course during my Master's studies in Computer Science.

The project explores the idea of identifying and visualizing crime hotspots in an urban environment using data-driven analysis and map-based representation.

## Project Overview

The prototype focuses on crime hotspot identification and visualization for Swiss urban areas. It combines a small Python-based web application with map outputs and supporting seminar documentation.

## Technologies

- Python
- Flask
- HTML templates
- Map visualization
- Fuzzy logic
- Data-driven urban analysis

## Repository Structure

- `app.py` — main application entry point
- `database.py` — data/database handling logic
- `fuzzy_logic.py` — fuzzy logic component
- `model.py` — model-related logic
- `static/` — static files and generated map outputs
- `templates/` — HTML templates
- `mid-term/` — mid-term seminar material
- `final/` — final report, presentation, and contribution documentation
