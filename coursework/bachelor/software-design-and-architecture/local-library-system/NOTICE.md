# Coursework Notice

This folder preserves a Bachelor group project completed for the **Design and Architecture of Software** course. The submitted materials are primarily in Macedonian.

## Public Cleanup

The public portfolio version:

- excludes lecture slides, exam summaries, question banks, and informal study notes;
- excludes the raw ZIP archive and the file containing student identification numbers;
- removes a hard-coded local PostgreSQL password from the original configuration;
- replaces production configuration with an environment-variable-based example;
- removes redundant raw OpenStreetMap JSON containing contact fields;
- retains the submitted software requirements specification, cleaned data pipeline artifacts, and database files;
- links to the original shared implementation repository instead of copying teammate-owned source code.

## Limitations

The project is preserved as historical Bachelor coursework rather than production-ready software. The requirements document contains some inconsistent numbering, wording, and ambitious reliability or performance assumptions typical of an early requirements-engineering exercise. The OpenStreetMap-derived location data may also be outdated.

No claim is made that the external implementation links remain executable or unchanged.
