# Data Attribution

The location dataset in this folder was derived during the coursework from OpenStreetMap data using `osmfilter` and `osmconvert`.

OpenStreetMap data is contributed by OpenStreetMap contributors. Public reuse should retain appropriate attribution and follow the applicable OpenStreetMap data terms:

https://www.openstreetmap.org/copyright

The dataset is preserved here as a historical coursework artifact and may not reflect current library or reading-room information.
