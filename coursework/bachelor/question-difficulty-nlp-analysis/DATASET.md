# Dataset Attribution

This project uses the **CMU Question/Answer Dataset**, Release 1.2.

The dataset contains manually written factual questions and answers based on Wikipedia articles. The S08, S09, and S10 files were collected through undergraduate question-generation activities involving Carnegie Mellon University and the University of Pittsburgh.

## Suggested Citation

Noah A. Smith, Michael Heilman, and Rebecca Hwa. 2008. *Question Generation as a Competitive Undergraduate Course Project*. Proceedings of the NSF Workshop on the Question Generation Shared Task and Evaluation Challenge.

## Source Fields

- `ArticleTitle`
- `Question`
- `Answer`
- `DifficultyFromQuestioner`
