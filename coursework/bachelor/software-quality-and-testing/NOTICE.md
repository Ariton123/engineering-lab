# Public Portfolio Notice

This folder is a curated public version of completed Bachelor laboratory coursework.

## Language

The assignment reports are written primarily in Macedonian, as originally submitted for the course.

## Authenticity and Scope

The Java source and tests are preserved substantially as originally submitted. They are included to document learning progression and should not be interpreted as production-quality implementations.

Known limitations in the archived coursework include:

- Assignment 1 contains a stray semicolon after an `if` condition in `CommonElements.java`, which changes the intended behavior.
- Assignment 1 mixes JUnit 4 and JUnit 5 imports and includes test expectations that do not consistently match the implementation.
- Assignment 4 mixes TestNG and JUnit APIs and uses shared mutable setup state, reducing test isolation.
- Assignment 5 was archived without a Maven or Gradle build definition, so the source is not directly reproducible without recreating the original dependency setup.
- The PIT report is preserved exactly as generated by PIT 1.7.4. Its metrics reflect the original project structure, where the test class was included in the analyzed package.

## Removed Material

The following were removed from the public package:

- student identification numbers in filenames and reports
- IDE configuration files
- compiled `.class` files and build output
- duplicate nested project folders
- the duplicate JMeter Word document
- five obsolete PIT report iterations
- the original ZIP archive

Only the final PIT report from the archived sequence is included.
