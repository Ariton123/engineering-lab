# Decentralized Auctions

This project was developed during the first semester of my Master's studies in Computer Science.

The application explores a decentralized auction system using blockchain-related technologies, smart contracts, and a web-based application architecture.

## Project Overview

The system combines a Solidity smart contract with a Node.js-based web application and supporting architectural documentation.

The goal of the project was to explore how decentralized technologies can be applied to auction systems, including transparency, ownership, bidding logic, and distributed trust.

## Technologies

- Solidity
- Node.js
- JavaScript
- SQL / database integration
- Web application development
- Architecture Design Language (ADL)
- Blockchain concepts
- Smart contracts

## Repository Structure

- `Auctions.sol` — Solidity smart contract for the auction logic
- `source/` — Node.js web application source code
- `adl_files_combined/` — architecture and system design documentation
- `Decentralized_Auctions_final.pptx` — final project presentation
